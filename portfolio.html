Projeto recente · Inteligência artificial

I-LLOPY AI - Catálogo com assistente de IA

Catálogo online responsivo com um assistente de inteligência artificial que responde dúvidas dos clientes a partir dos documentos da loja, integrando a experiência de e-commerce a uma API própria.

  • Chat integrado ao catálogo com respostas em português e indicação das fontes consultadas.
  • Arquitetura RAG com processamento de PDFs, embeddings e busca semântica em índice vetorial FAISS.
  • Integração com Google Gemini para gerar respostas contextualizadas sobre entregas, trocas e políticas da loja.
  • Frontend no GitHub Pages e backend na Oracle Cloud Infrastructure, com Nginx e HTTPS.

Tecnologias: HTML5, CSS3, JavaScript, Python, FastAPI, Google Gemini, Sentence Transformers, FAISS, PyPDF, OCI e Nginx.

Projeto recente · Gestão financeira

OpyZin - Gestão financeira pessoal

Aplicação web para organizar as finanças pessoais, acompanhar receitas e despesas e planejar metas de economia. Desenvolvida com foco em dispositivos móveis e instalação como PWA.

  • Dashboard com gráficos, saldo, comparação mensal e despesas por categoria.
  • Gestão de contas, cartões, receitas, despesas e contas recorrentes com lembretes de vencimento.
  • Metas mensais de economia e exportação dos dados em CSV e Excel.
  • Autenticação em duas etapas, dados separados por usuário e sincronização entre dispositivos.

Tecnologias: TypeScript, Vite, PWA, Cloudflare Pages, Pages Functions e banco de dados Cloudflare D1.

Integrações · APIs públicas

BuscaCEP - Consulta de endereços

Site desenvolvido para consultar endereços a partir de um CEP informado pelo usuário, com preenchimento automático dos dados retornados pela API. O projeto também permite busca por rua, cidade e UF.

  • Consulta de endereço por CEP usando BrasilAPI.
  • Busca por rua, cidade e UF usando ViaCEP.
  • Carregamento de estados e cidades com dados do IBGE.
  • Interface responsiva com campos de formulário e botões de busca.

Tecnologias: HTML5, CSS3, JavaScript ES6, Fetch API, BrasilAPI, ViaCEP e API de localidades do IBGE.
